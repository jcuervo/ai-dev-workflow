# Files Claude may not edit directly. One glob per line, matched against the
# path relative to the repo root and against the file name.
# Optional reason after "|". A leading "!" re-allows a path (later lines win).

# Secrets
.env                        | Secrets file. Ask the user to change it.
.env.*                      | Secrets file. Ask the user to change it.
!.env.example
!.env.sample
!.env.template
config/master.key           | Rails master key. Never edit.
config/credentials/*.key    | Rails credentials key. Never edit.
config/credentials*.yml.enc | Encrypted credentials. Use `bin/rails credentials:edit`, which the user must run.
*.pem                       | Key or certificate. Ask the user.
*.p12                       | Key or certificate. Ask the user.

# Generated files
db/schema.rb                | Generated. Write a migration and run it instead of editing the schema.
db/structure.sql            | Generated. Write a migration and run it instead of editing the schema.
Gemfile.lock                | Generated. Change the Gemfile and run `bundle install` / `bundle update <gem>`.
yarn.lock                   | Generated. Use yarn to change dependencies.
package-lock.json           | Generated. Use npm to change dependencies.
pnpm-lock.yaml              | Generated. Use pnpm to change dependencies.
